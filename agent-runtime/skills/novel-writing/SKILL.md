# 中文小说单章写作 Skill

## 最高优先级

1. 本章必须是一个完整的小故事：有场景目标、阻力、转折、收束和章末钩子。
2. 必须和上一章、当前状态、本章大纲因果衔接；不能靠巧合推进。
3. 开头必须让读者知道：谁、在哪、正在做什么、为什么现在要做。
4. 本章目标必须在章末前有一个明确结果（成功、失败、放弃或换方案），不能只停在“决定去做”。
5. 大纲的 hook 必须是本章最后一拍；hook 出现后不得另起新场景。
6. 结尾必须是有意设计的钩子，不能写到一半突然停。
7. 最后一场戏必须完成动作—反应：人物拨号、发问、推门、按下按钮或提出请求后，必须写出结果、回应或明确中断，不能停在人物刚开口的位置。
8. 语言要像人写的：段落长短不一，句子长短交替，少解释，多具体动作和细节。

## 一、先搭本章骨架

动笔前在内部确认这六件事，不要把它们写进正文：

- 本章目标：人物这一章想得到/阻止什么
- 开场画面：读者第一眼看到的具体动作、声音、物件或对话
- 阻力升级：谁或什么在阻挡，代价如何变大
- 转折：人物发现/决定/失去什么，局面因此改变
- 收束：本章目标得到什么结果，核心冲突如何暂时落地
- 章末钩子：哪个具体后果把下一章的问题带出来（必须是最后一拍）

如果大纲信息不足，用已有人物、状态和伏笔补足。不要新增有名字的角色，不要改掉大纲的核心事件。

## 二、开头：落地，不要硬接上一章

禁止：

- 用“上一章……”“与此同时……”“不知道过了多久……”开头
- 第一句就是没有主语的碎片，或直接复制上一章最后一句
- 先讲背景、世界观、天气、回忆，再进入场景
- 用“他/她”开头，但前三段还没让读者知道这是谁

必须：

- 第一段出现具体动作、对话、声音、物件或身体感受
- 前三段内交代 POV、地点、时间或处境
- 和上一章结尾有因果关系，但不是复述
- 第一段就给读者一个“现在要发生什么”的牵引

## 三、中段：因果链，不要靠巧合

- 每个场景都要有“谁想要什么 → 谁/什么阻挡 → 付出什么代价 → 得到什么结果”
- 人物做决定要有动机；动机来自已经建立的目标、恐惧、关系或利益
- 冲突升级要具体：时间变少、代价变大、选择变难、秘密暴露
- 不要用“突然”“恰好”“没想到”解决问题；转折必须在前文有铺垫
- 严格遵守当前状态：人物位置、伤势、关系、已知信息、物品、伏笔
- 人物不能突然知道不该知道的事，不能瞬移，不能无代价使用能力
- 对话要有潜台词和目的，不要用对话解释设定
- 描写要服务于动作、情绪或信息，不要堆形容词

## 四、结尾：先收住，再抛钩子

- 先收束本章的核心冲突，让读者知道这一场结束了
- 再用一个具体动作、决定、发现或后果把下一章的问题抛出来
- 最后一场戏必须有结果：如果是通话，必须写出对方的回应和人物的下一步；如果是发问，必须写出回答或明确的中断；不能停在“喂”“你说”“哪位”这类刚开口的话上
- 大纲 hook 如果是信息揭示，必须放在最后一场戏里揭示；不要在中段揭示完再另起一场没有结局的戏
- 最后一句话必须是完整句子，不能是半句，不能停在“……”。
- 禁止总结式结尾：“就这样……”“这一天……”“他明白了很多……”
- 禁止升华式结尾：“命运的齿轮……”“一切才刚刚开始……”
- 禁止用空泛反问当钩子：“接下来会发生什么？”
- 如果字数快到了但钩子还没到，压缩前面的过场，不要砍结尾

## 五、去 AI 味：打破统计规律

### 段落

- 段落长度必须不均匀：至少一段只有 1-2 句，至少一段 5 句以上
- 不要每段都“观点 + 解释 + 总结”
- 不要每段开头都用同一种句式

### 句子

- 长短句交替；长句后接短句
- 相邻三句不能是同一结构
- 允许省略句、口语断句、自我打断
- 少用“缓缓地、轻轻地、深深地、猛地、瞬间、不禁、竟然、仿佛、似乎”堆叠
- 一段最多一个比喻；不要连续比喻

### 词汇黑名单（正文中禁止）

值得注意的是、综上所述、总而言之、与此同时、毫无疑问、不言而喻、换句话说、本质上、归根结底、首先/其次/最后、不仅……而且……、既……又……、不是……而是……（连续使用）

空气仿佛凝固了、心中五味杂陈、嘴角勾起一抹、眼底闪过一丝、不由自主地、仿佛整个世界都安静了、这一刻他/她终于明白、命运的齿轮开始转动、时间仿佛静止、一种……的感觉涌上心头、无声地诉说、这一切的一切

### 表达

- 用具体动作代替情绪总结：不写“他很愤怒”，写他做了什么
- 少解释人物心理，让动作和对话承担
- 不写“作者视角”的评论、总结、提醒
- 不写“本章”“接下来”“故事还要从……”等元叙述
- 不强行升华，不喊口号，不和稀泥
- 数字、地名、专有名词只在具体、必要时使用

## 六、字数与节奏

- 以本章目标字数为准，允许上下浮动约 15%
- 宁可少写一个过场，也不要注水
- 不要为了凑字数重复信息、反复描写同一情绪
- 不要为了压字数砍掉转折或钩子
- 一章只完成本章大纲边界内的事，不提前写下一章

## 七、输出前自检

- [ ] 开头三段内能回答：谁、在哪、在做什么、为什么现在
- [ ] 本章有目标、阻力、转折、收束、钩子
- [ ] 结尾是完整句子，且是有意设计的钩子
- [ ] 没有场景中途突然结束
- [ ] 人物行为有动机，转折有铺垫
- [ ] 和上一章结尾、当前状态、本章大纲一致
- [ ] 没有新增有名字的角色
- [ ] 段落长短不一，句子结构有变化
- [ ] 没有黑名单词汇和连续比喻
- [ ] 没有总结式或升华式结尾
- [ ] 没有元叙述和作者解释
