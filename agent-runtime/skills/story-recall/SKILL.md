# 长篇记忆分层检索 Skill

## 三层记忆

1. **滚动摘要（rolling summary）**：每 5 章一块，用 3–4 句话概括一个时间段。它只用于定位“事情大致发生在哪几章”，不用于写具体细节。
2. **本章摘要（chapter brief）**：每章 2–3 句，只概括本章核心事件、人物选择或结果、章末钩子。它用于确认事件之间的因果和本阶情感落点。
3. **章节全文（chapter full text）**：最高保真，包含精确对话、动作、数字、承诺、物件和钩子原文。

此外还有**章节档案（digest）**：按章记录核心设定、人物、关系变化、情节节点和伏笔动作，用于核对结构化事实；它不代替原文。

## 上下文里已经有什么

写第 N 章时，默认注入：

- 第 N-1 章：全文；
- 第 N-9 章到第 N-2 章：逐章摘要；
- 第 N-14–N-10 章、第 N-19–N-15 章、第 N-24–N-20 章……：滚动摘要块。

除此之外的更早章节不在上下文里，需要主动检索。

## 检索顺序

1. **先看已有滚动摘要**：判断事情大致落在哪个 5 章块。上下文里没有该块时，调用 `story_recall({ level: "rolling", fromChapter, toChapter })`。
2. **再展开逐章摘要**：用 `story_recall({ level: "chapter", fromChapter, toChapter })` 找到具体是哪一章、谁做了什么、留下了什么钩子。
3. **最后核对全文**：涉及精确对话、动作顺序、数字、时间、伤口、物件、承诺或伏笔原文时，必须调用 `chapter_read({ chapterNumber })` 回查当前章之前的章节。
4. **查结构化事实**：人物关系时间线、地点、物品、概念、事件、伏笔连线，用 `story_graph`；需要章节核心设定、人物状态、关系变化、伏笔动作，用 `story_digest`。

## 硬性规则

- 先粗后细：不要跳过滚动摘要直接逐章扫；也不要在滚动摘要上补写具体细节。
- 本章摘要只能用于判断“发生了什么”，不能当作原文引用。数字、承诺、物件、伤口和伏笔原句必须回查全文。
- 本章要推进、回收或呼应伏笔时：先看伏笔账本的设置章，用 `story_recall` 展开设置章附近的逐章摘要，再用 `chapter_read` 核对伏笔原文。
- 本章要承接旧钩子时：先在逐章摘要里确认钩子来自哪一章，再用 `chapter_read` 读该章结尾，不要凭滚动摘要猜测。
- 上下文已有的内容不要重复调用工具；只有信息不足、冲突或需要原文时才升级检索。
- 不得检索当前章及之后的章节，也不得用摘要编造未来剧情；当前章正文由你直接创作，不读取旧稿。
